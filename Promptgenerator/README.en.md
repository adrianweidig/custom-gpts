# PromptForge

Languages: [Deutsch](README.md) | [English](README.en.md)

Local project folder for the public GPT `PromptForge`.

## ChatGPT Link

https://chatgpt.com/g/g-6a0ac654618c81919f30c2da2be089c8-promptforge

## Local Folder Name

In this repository, the GPT is stored under `Promptgenerator`.

## Purpose

This GPT creates robust, reusable prompts for business, education, research, coding, support, documentation and automation. It focuses on clear roles, input requirements, constraints, output formats and reviewable assumptions.

## Included Files

| File | Purpose |
|---|---|
| `customgpt_infos.md` | GPT metadata and configuration notes |
| `systemprompt.md` | Prompt generation logic and output rules |
| `fachwissen.md` | Prompt engineering knowledge |
| `bootloader.md` | Compact GPT setup text |
| `beispiel.md` | Example prompt artifact |

## Internationalization

German is the repository default. The GPT can switch to the user's language when the task requires it. Prompt variables, placeholders and technical identifiers must remain consistent across languages.
