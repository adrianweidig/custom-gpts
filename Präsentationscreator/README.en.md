# Präsentationscreator

Languages: [Deutsch](README.md) | [English](README.en.md)

Local project folder for the public GPT `Präsentationscreator`.

## ChatGPT Link

https://chatgpt.com/g/g-69fdf8ef05c08191bb3a5454c597baa7-prasentationscreator

## Purpose

This GPT creates browser-based presentations that can be used like a modern web keynote. It focuses on storyline, visual quality, animation, usability and directly runnable HTML results without a build process.

## Included Files

| File | Purpose |
|---|---|
| `customgpt_infos.md` | GPT metadata and configuration notes |
| `systemprompt.md` | Presentation generation logic |
| `fachwissen.md` | Layout, UI and interaction knowledge |
| `bootloader.md` | Compact GPT setup text |
| `beispiel.md` | Example presentation artifact |

## Typical Use

Use this package to create HTML-based presentations, visual prototypes or presentation-ready web pages from structured input.

## Internationalization

German is the default language. Generated presentations should set `<meta charset="UTF-8">` and can use the requested audience language. Technical HTML, CSS and JavaScript identifiers are not translated.
