# Support

Dieses Repository wird seit dem 24. Mai 2026 nicht mehr aktiv weiterentwickelt. Die Inhalte bleiben als öffentliche Sammlung von Custom-GPT-Artefakten nutzbar, es gibt aber keinen verbindlichen Support und keine zugesagte Reaktionszeit.

## Geeignete Support-Anfragen

- Fragen zur Repository-Struktur
- Hinweise auf defekte Links oder unklare Dokumentation
- Verständnisfragen zu einem GPT-Ordner
- Vorschläge für bessere Problemfall-Briefings
- Meldungen zu fehlenden Sicherheits-, Datenschutz- oder Lizenzhinweisen

## GitHub Issues

Nutze [GitHub Issues](https://github.com/adrianweidig/custom-gpts/issues), wenn deine Anfrage öffentlich diskutiert werden kann.

Issues dienen primär der Dokumentation von Hinweisen für spätere Leserinnen und Leser. Eine Bearbeitung, Priorisierung oder Umsetzung ist nicht verbindlich zugesagt.

Bitte gib an:

- betroffener GPT-Ordner oder Datei
- erwartetes Verhalten oder erwartete Information
- beobachtetes Problem
- relevante Links oder Ausschnitte ohne sensible Inhalte

## Kein öffentlicher Kanal für Secrets

Poste keine Tokens, API-Keys, Passwörter, privaten Daten, Kundendaten oder vertraulichen Architekturdetails. Für Sicherheitsprobleme gilt [`SECURITY.md`](SECURITY.md).

## Kein Produktsupport für externe Plattformen

Dieses Repository ersetzt nicht den Support von ChatGPT, OpenWebUI, n8n oder anderen Plattformen. Plattformfehler, Accountfragen und produktive Betriebsprobleme müssen beim jeweiligen Anbieter oder intern im betroffenen System geklärt werden.
