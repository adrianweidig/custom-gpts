# Support

Languages: [Deutsch](SUPPORT.md) | [English](SUPPORT.en.md)

This repository has not been actively developed since 24 May 2026. The contents remain usable as a public collection of Custom GPT artifacts, but there is no guaranteed support and no promised response time.

## Suitable Support Requests

- questions about the repository structure
- notes about broken links or unclear documentation
- questions about a GPT folder
- suggestions for better problem briefings
- reports of missing security, privacy or license notes

## GitHub Issues

Use [GitHub Issues](https://github.com/adrianweidig/custom-gpts/issues) when your request can be discussed publicly.

Issues primarily document notes for later readers. Processing, prioritization or implementation is not guaranteed.

Please include:

- affected GPT folder or file
- expected behavior or expected information
- observed problem
- relevant links or excerpts without sensitive content

## No Public Channel for Secrets

Do not post tokens, API keys, passwords, private data, customer data or confidential architecture details. For security issues, follow [`SECURITY.en.md`](SECURITY.en.md).

## No Product Support for External Platforms

This repository does not replace support for ChatGPT, OpenWebUI, n8n or other platforms. Platform errors, account questions and production operations issues must be handled by the respective provider or inside the affected system.
