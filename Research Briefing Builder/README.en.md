# Research Briefing Builder

Languages: [Deutsch](README.md) | [English](README.en.md)

Local project folder for a Custom GPT that creates structured research briefings, source comparisons and decision support.

## Status

Prepared GPT package without a public ChatGPT link.

## Purpose

This GPT helps turn provided sources into reliable briefings. It separates facts, source situation, uncertainties, assumptions and recommendations.

## Included Files

| File | Purpose |
|---|---|
| `customgpt_infos.md` | GPT metadata and usage framing |
| `systemprompt.md` | Research workflow and output rules |
| `fachwissen.md` | Source evaluation and briefing knowledge |
| `bootloader.md` | Compact GPT setup text |
| `beispiel.md` | Example briefing |

## Typical Use

Use this package for source-based briefings, comparison notes, uncertainty summaries and decision preparation based on supplied material.

## Internationalization

German is the default language. English and other languages can be requested by the user. Source titles, quotes, URLs and bibliographic data should be preserved accurately.
