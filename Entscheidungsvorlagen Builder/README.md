# Entscheidungsvorlagen Builder

Lokaler Projektordner für einen Custom GPT zur Erstellung klarer Entscheidungsunterlagen, Optionenvergleiche und Management-Memos.

## Status

Konzipiertes GPT-Paket ohne öffentlichen ChatGPT-Link.

## Zweck

Dieser GPT strukturiert unklare Entscheidungssituationen in Optionen, Kriterien, Risiken, Annahmen, Empfehlung und nächste Schritte. Er soll Entscheidungen nicht ersetzen, sondern transparent vorbereiten.

## Enthaltene Dateien

- `customgpt_infos.md`: Positionierung, Zielgruppe, Einsatzgebiete und Konfiguration.
- `fachwissen.md`: Entscheidungslogik, Kriterienmatrix, Risiko- und Annahmenarbeit.
- `systemprompt.md`: Hauptlogik für Entscheidungsunterlagen.
- `bootloader.md`: kompakter Hinweistext für das Instructions-Feld.
- `beispiel.md`: Muster-Memo für eine technische Toolentscheidung.

## Typische Nutzung

- Optionen vergleichen
- Entscheidungsvorlagen für Meetings erstellen
- Risiken und Annahmen sichtbar machen
- Empfehlungen mit Bedingungen formulieren
- offene Punkte für Entscheider vorbereiten

## Hinweise

- Der GPT trifft keine verbindlichen Entscheidungen.
- Rechtliche, finanzielle oder sicherheitskritische Entscheidungen müssen fachlich geprüft werden.
