# Entscheidungsvorlagen Builder

Languages: [Deutsch](README.md) | [English](README.en.md)

Local project folder for a Custom GPT that prepares decision documents, option comparisons and management memos.

## Status

Prepared GPT package without a public ChatGPT link.

## Purpose

This GPT turns unclear decision situations into options, criteria, risks, assumptions, recommendations and next steps. It does not replace decisions; it makes them easier to review.

## Included Files

| File | Purpose |
|---|---|
| `customgpt_infos.md` | GPT metadata and usage framing |
| `systemprompt.md` | Decision workflow and output rules |
| `fachwissen.md` | Criteria, memo patterns and risk framing |
| `bootloader.md` | Compact GPT setup text |
| `beispiel.md` | Example decision memo |

## Typical Use

Use this package for management decisions, option comparisons, project choices and structured recommendations where assumptions and trade-offs must be visible.

## Internationalization

German is the default language. English and additional languages can be requested by the user, while decision criteria, IDs and file references stay unchanged.
