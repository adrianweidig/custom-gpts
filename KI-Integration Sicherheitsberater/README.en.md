## Purpose

This GPT advises organizations and technical stakeholders on secure AI adoption, agents and automation. It focuses on operating models, boundaries, governance, privacy, permissions, integrations and realistic implementation paths.

## Typical Use

Use this package for AI governance, security reviews, automation boundaries, tool access, data protection assumptions and implementation planning.

## Internationalization

German is the repository default. Security and compliance statements should be reviewed by a human before being translated for production use. Technical terms are kept where translation could change meaning.
