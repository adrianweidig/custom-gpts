# Unterrichtsfolien & Handout Builder

Languages: [Deutsch](README.md) | [English](README.en.md)

Local project folder for the public GPT `Unterrichtsfolien & Handout Builder`.

## ChatGPT Link

https://chatgpt.com/g/g-6a071be465ac8191b27a4b5fb5789b0a-unterrichtsfolien-handout-builder

## Purpose

This GPT turns curricula, domain sources, notes or existing presentations into didactically structured lesson slides and printable handouts. It focuses on usable teaching material rather than loose text fragments.

## Included Files

| File | Purpose |
|---|---|
| `customgpt_infos.md` | GPT metadata and configuration notes |
| `systemprompt.md` | Teaching material generation logic |
| `fachwissen.md` | Didactic and content rules |
| `layoutrichtlinien.md` | Layout guidelines |
| `bootloader.md` | Compact GPT setup text |
| `beispiel.md` | Example teaching artifact |

## Typical Use

Use this package for schools, nursing education, medical teaching, training courses and didactic revision of existing presentations.

## Internationalization

German is the default language. Teaching materials can be generated in another language when requested. Domain terminology, citations and safety-relevant wording should be reviewed by a human before use.
