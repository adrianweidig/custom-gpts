# Code of Conduct

Dieses Repository soll sachliche, respektvolle und produktive Zusammenarbeit ermöglichen.

## Erwartetes Verhalten

- freundlich und respektvoll kommunizieren
- Kritik konkret an Dateien, Aussagen oder Änderungen festmachen
- unterschiedliche Erfahrungsstände berücksichtigen
- fachliche Risiken klar benennen, ohne Personen abzuwerten
- keine vertraulichen Informationen veröffentlichen

## Nicht akzeptables Verhalten

- persönliche Angriffe, Beleidigungen oder abwertende Kommentare
- Belästigung, Diskriminierung oder einschüchternde Kommunikation
- Veröffentlichung privater oder vertraulicher Informationen
- absichtliches Einbringen von Secrets, Schadcode oder irreführenden Sicherheitsversprechen
- wiederholtes Ignorieren klarer Maintainer-Hinweise

## Durchsetzung

Maintainer können Issues, Pull Requests oder Kommentare moderieren, schließen oder entfernen, wenn sie gegen diese Regeln verstoßen. Wiederholte oder schwere Verstöße können zum Ausschluss von der Mitarbeit führen.

## Melden

Melde problematisches Verhalten über einen angemessenen GitHub-Kanal. Sicherheitsrelevante Inhalte gehören nicht in öffentliche Issues; nutze dafür [`SECURITY.md`](SECURITY.md).
