# CustomGPT Studio

Languages: [Deutsch](README.md) | [English](README.en.md)

Local project folder for the public GPT `CustomGPT Studio`.

## ChatGPT Link

https://chatgpt.com/g/g-6a06ef9be6fc819197d7b815debd0f57-customgpt-studio

## Purpose

This GPT creates complete, structured project packages for professional Custom GPTs. The goal is not a loose single prompt, but a reproducible set of description, knowledge base, system prompt, bootloader and example artifact.

## Included Files

| File | Purpose |
|---|---|
| `customgpt_infos.md` | Public-facing GPT metadata and configuration notes |
| `systemprompt.md` | Main behavior and generation rules |
| `fachwissen.md` | Structural knowledge for Custom GPT packages |
| `bootloader.md` | Compact setup text |
| `beispiel.md` | Example output |

## Typical Use

Use the GPT to design a new Custom GPT package with coherent instructions, boundaries, knowledge files and a usable example artifact.

## Internationalization

German is the repository default. The GPT can produce artifacts in another language when the user requests it. Technical filenames and import-relevant values remain stable.
