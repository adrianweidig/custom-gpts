# Security Policy

Languages: [Deutsch](SECURITY.md) | [English](SECURITY.en.md)

This repository contains prompt, knowledge and documentation artifacts. It does not contain a production application, server process or central runtime.

## Supported State

Security and privacy notes refer to the current `main` branch. Versioned releases do not currently exist.

## What Counts as a Security Issue

- accidentally published secrets, tokens, passwords, API keys or private keys
- personal data, confidential customer data or internal architecture details
- prompt contents that clearly encourage unsafe automation, credential disclosure or misleading security guarantees
- documentation that suggests production use without necessary security, privacy or license review

## Reporting

Please do not post sensitive vulnerability details publicly as an issue.

If GitHub Private Vulnerability Reporting is available for this repository, use the repository's Security area. If that path is unavailable, contact the maintainer through a non-public channel already known to you and share only the minimum necessary details.

## Expected Handling

1. Review the report.
2. Clarify reproducibility and affected files.
3. Remove or defuse sensitive information where needed.
4. Adjust documentation, `.gitignore` or review rules.
5. Respond where a contact path is available.

## Limits

This repository provides no security guarantee for generated workflows, model packages, presentations or teaching materials. Domain, legal, privacy and technical review is required before production use.
